# bRainDead · 레인 데드

Godot 4.7.2로 만든 2D 물리 조작 게임 프로토타입입니다. 바람으로 버려진 우산을 움직여, 멋대로 집에 가는 민트를 비로부터 보호합니다.

## 실행

`project.godot`을 Godot 4.7.2에서 열고 **F5**를 누르세요. 메인 씬은 `scenes/main.tscn`입니다. 플러그인, 외부 에셋, .NET은 필요하지 않습니다.

| 키 | 동작 |
| --- | --- |
| A / ← | 누르는 동안 왼쪽 바람 |
| D / → | 누르는 동안 오른쪽 바람 |
| 양쪽 동시 입력 / 입력 없음 | 바람 없음 |
| Enter / Space | 타이틀에서 시작, 스테이지 대기 화면에서 출발 |
| R | 플레이·실패·일시정지 중 즉시 재시작 |
| Esc | 일시정지 / 계속 / 이전 화면 |
| M | 음향 켜기·끄기 |

## 구현한 규칙

- 우산은 `RigidBody2D`입니다. 바람은 수평 힘, 위쪽 힘, 회전력을 동시에 가합니다. 입력을 끊어도 관성이 남고 공기 저항과 중력이 작용합니다. 반대 바람과 장애물 충돌로 회전·이동을 되돌릴 수 있습니다.
- **플레이어 우산은 뒤집혀도 비를 막습니다.** 자동 자세 복구는 없습니다.
- 비는 고정 간격으로 생성되어 수직으로 내려옵니다. 각 빗방울의 이전 위치에서 다음 위치까지 Godot 물리 공간에 충돌 검사를 하여 빠른 빗방울의 관통을 방지합니다. 처음 닿은 곳에서 소멸합니다.
- 플레이어 우산, 바닥, 간판은 비를 막습니다. **행인과 행인 우산은 비 판정에서 제외되므로 민트를 보호하지 않습니다.** 행인 우산은 시야를 가리고 플레이어 우산과 물리적으로 부딪힙니다.
- 민트에게 닿는 빗방울 수와 관계없이 젖음은 **초당 1초 증가**, 보호받으면 **초당 1초 감소**합니다. 0~2초로 제한되며 2초에 도달하면 실패합니다. 실제 빗방울 사이의 빈 프레임은 0.055초의 접촉 유지 시간으로 이어줍니다.
- 민트는 젖음에 비례하여 파란색으로 변합니다. 길 오른쪽의 집에 도착하면 클리어합니다.
- 민트 행동, 행인 경로, 비 생성 패턴에 랜덤 요소가 없습니다. 재시작하면 우산의 위치·속도·회전, 민트, 행인, 비를 초기화합니다.
- 4개 스테이지는 순서대로 해금됩니다. 클리어와 시도 횟수는 Godot의 `user://progress.cfg`에 저장합니다.
- 클리어 후 ‘다음으로’를 누르면 **2초짜리 광고 대체 화면**을 표시하고 스테이지 선택으로 돌아갑니다.

## 스테이지와 조정 위치

| 파일 | 내용 |
| --- | --- |
| `stages/01_walk.tres` | 일정 속도로 걷기 |
| `stages/02_run.tres` | 고정 위치에서 달리기 시작 |
| `stages/03_trip.tres` | 같은 위치에서 달리다가 고정 위치에서 넘어지고, 2.6초 후 일어나 걷기 |
| `stages/04_crowd.tres` | 고정 경로의 행인 21명이 있는 번화가 |

각 `.tres`를 Godot Inspector에서 열면 길이, 이동 속도, 달리기·넘어짐 위치, 정지 시간, 우산 시작 위치, 간판 위치를 바꿀 수 있습니다. 좌표는 민트의 발 위치를 기준으로 하며 바닥은 Y=600입니다. 화면은 1280×720 기준이며 민트를 따라 횡으로 이동합니다.

우산의 수평 힘·상승 힘·회전력·속도 제한은 `scenes/umbrella.tscn`의 Inspector에서 조정할 수 있습니다. 중력·감속은 `scripts/umbrella.gd`에 있습니다. 현재 값은 첫 플레이가 가능한 초깃값이며 최종 난이도 수치는 아닙니다.

## 구조

- `scripts/main.gd`: 타이틀, 선택, 대기, 플레이, 일시정지, 실패, 클리어, 광고 및 저장
- `scripts/stage.gd`: 지형·캐릭터·우산·비 구성 및 스테이지 진행
- `scripts/mint.gd`: 위치 기반 행동, 넘어짐, 젖음 및 캐릭터 그리기
- `scripts/umbrella.gd`: 바람 물리와 우산 그리기
- `scripts/rain.gd`: 고정 패턴의 물리 충돌 비
- `scripts/pedestrian.gd`: 고정 경로의 행인 및 비를 막지 않는 우산
- `scripts/city.gd`: 직접 그린 벡터 도시 배경
- `scripts/sound.gd`: 외부 파일 없이 합성한 빗소리와 효과음

한국어는 시스템의 맑은 고딕 / Noto Sans CJK KR / Apple SD Gothic Neo를 사용합니다. 그래픽은 Compatibility 렌더러를 사용합니다.

## 검증

Godot 실행 파일을 PATH에 등록했다면 다음 명령으로 실제 엔진 기반 검사를 실행할 수 있습니다.

```powershell
godot --headless --path . --editor --import --quit
godot --headless --path . --script res://tests/gameplay_test.gd -- --no-save
godot --headless --path . --script res://tests/physics_playtest.gd --fixed-fps 60 -- --no-save
```

Windows에서는 아래 도우미도 사용할 수 있습니다. 검사 프로필은 임시 폴더로 분리하여 실제 플레이 기록을 건드리지 않습니다.

```powershell
powershell -ExecutionPolicy Bypass -File tools/run_checks.ps1 -GodotPath 'C:\path\to\Godot_console.exe'
```

검사 범위: 플레이어·행인 우산 비 충돌, 뒤집힌 우산의 보호, 젖음 증가·회복·사망, 비 밀도 독립성, 고정 행동·행인·비 패턴, 재시작, 일시정지, 해금, 저장, 광고 후 복귀.

`physics_playtest.gd`는 플레이어와 같은 왼쪽·오른쪽·무입력만 사용해 4개 스테이지를 끝까지 진행하는 자동 조작 검사입니다. 우산이나 민트의 위치를 강제로 옮기지 않습니다. 2스테이지에서는 양쪽 바람을 번갈아 사용해 간판보다 높은 경로를 택합니다. 자동 조작은 테스트에서만 동작합니다.

저장을 생략하고 특정 스테이지를 미리 보려면 다음처럼 실행합니다. 잠금 해제 기록은 바뀌지 않습니다.

```powershell
godot --path . -- --no-save --stage=4
```

## 현재 범위

임시 벡터 그래픽과 합성 음향을 사용하는 플레이 가능한 프로토타입입니다. 실제 광고 SDK와 최종 아트·애니메이션은 포함하지 않습니다.
